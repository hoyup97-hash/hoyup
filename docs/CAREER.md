## 1. 콘텐츠 구성 원칙 (2026-07-31 — "하나하나가 커리어" 방침)

기존 계획은 프로젝트 4개만 상세히 다루고 나머지를 타임라인 한 줄로 눌렀다. **이 방침을 폐기한다.**
경험 하나하나가 각자의 서사·과정·증거를 가진 독립 케이스가 되도록 3단 구조로 나눈다.

| 등급 | 취급 | 구성 요소 | 해당 유닛 |
|---|---|---|---|
| **T1** | 전용 상세 페이지 | 배경 → 과정 → 전환점 → 결과 → 배운 것 + 증거물 | U1 U2 U3 U4 U7 |
| **T2** | 메인 인페이지 확장 카드 (`details/summary`) | 요약 2문장 + 펼치면 과정 3~5문단 | U5 U8 U9 |
| **T3** | 타임라인 한 줄 | 사실만 | U6 U10 |

**모든 T1·T2 유닛이 반드시 갖춰야 할 4요소** — 하나라도 비면 그 유닛은 "나열"이지 "커리어"가 아니다.
1. **왜 시작했나** (동기·문제 인식)
2. **어떻게 했나** (과정 — 여기가 가장 길어야 한다)
3. **무엇이 틀렸고 어떻게 고쳤나** (전환점 — 이게 있어야 실무자로 읽힌다)
4. **증거** (수치 + 이미지/문서)

|---|---|---|
| 군 행정 효율화 | "5명이 매일 1시간씩 → 1명이 매일 10분" (한국재정정보원) | 서류 통과 |

→ **사이트의 모든 카피는 형용사가 아니라 숫자로 쓴다.** "많은", "크게", "성공적으로" 금지.
